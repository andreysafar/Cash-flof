# Политика конфиденциальности

_Шаблон. Перед публикацией с рекламой разместите финальный текст по публичному
URL и укажите его в карточке RuStore._

**Приложение:** «Денежный поток — финансовый отчёт»

## Какие данные обрабатываются

- **Игровой финансовый отчёт** (профессия, суммы, операции) хранится **только
  локально** на устройстве (файл в приватном хранилище приложения) и не
  передаётся на серверы разработчика.
- Приложение **не запрашивает** аккаунты, контакты, геолокацию, камеру и т.п.

## Реклама

Если в сборке включена реклама (RuStore Ads), рекламный SDK может для показа
объявлений получать обезличенные технические данные устройства и сетевое
соединение в соответствии с политикой рекламной сети RuStore. Состав данных и
их обработку определяет провайдер рекламы; ознакомьтесь с условиями RuStore Ads.

Версия без рекламы работает полностью офлайн и не использует сеть.

## Хранение и удаление

Данные отчёта удаляются при удалении приложения, очистке его данных в настройках
ОС или нажатии «Сбросить отчёт» внутри приложения.
