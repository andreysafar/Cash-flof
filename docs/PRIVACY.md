# Политика конфиденциальности

_Шаблон. Перед публикацией с рекламой разместите финальный текст по публичному
URL и укажите его в карточке RuStore._

**Приложение:** «Денежный поток — финансовый отчёт»

## Какие данные обрабатываются

- **Игровой финансовый отчёт** (профессия, суммы, операции) хранится **только
  локально** на устройстве (файл в приватном хранилище приложения) и не
  передаётся на серверы разработчика.
- Приложение **не запрашивает** аккаунты, контакты, геолокацию, камеру и т.п.

## Реклама

Приложение использует рекламный SDK **VK Рекламы** (VK Ad SDK / myTarget) для
показа баннеров и межстраничной рекламы. Для этого требуется сетевое
соединение. SDK может получать обезличенные технические данные устройства
(включая рекламный идентификатор, если доступен) в соответствии с политикой
[Рекламной сети VK](https://ads.vk.ru/help/partner/partner_integration/partner_android/partner_android_integration).

Игровой финансовый отчёт по-прежнему хранится только локально и не передаётся
разработчику через рекламный SDK.

## Хранение и удаление

Данные отчёта удаляются при удалении приложения, очистке его данных в настройках
ОС или нажатии «Сбросить отчёт» внутри приложения.
