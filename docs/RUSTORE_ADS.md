# Реклама в приложении

> **Актуальная инструкция:** [VK_ADS.md](VK_ADS.md)

Монетизация реализована через **VK Ad SDK** (myTarget), а не через отдельный RuStore Ads SDK.
Два формата: баннер 320×50 + межстраничная реклама. Настройка ID блоков — в `AdConfig.kt`.

Старый черновик с `ru.rustore.sdk:adsdk` не используется.
