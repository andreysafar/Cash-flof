# Публикация на RuStore

Чек-лист подготовки релиза «Денежный поток — финансовый отчёт».

## 1. Подпись релиза (keystore)

RuStore принимает подписанный AAB/APK. Создайте ключ (один раз):

```bash
keytool -genkeypair -v -keystore cashflow-release.jks \
  -alias cashflow -keyalg RSA -keysize 2048 -validity 10000
```

Положите рядом с проектом файл `keystore.properties` (он **не коммитится**,
см. `.gitignore` и `keystore.properties.sample`):

```properties
storeFile=/абсолютный/путь/cashflow-release.jks
storePassword=********
keyAlias=cashflow
keyPassword=********
```

`app/build.gradle.kts` автоматически подхватит его для release-сборки. Без
файла release подпишется debug-ключом (только для локальной проверки, в RuStore
такой не загружайте).

> Храните `.jks` и пароли надёжно: смена ключа подписи после публикации
> в RuStore невозможна без процедуры обновления ключа.

## 2. Версия

Перед каждой загрузкой повышайте в `app/build.gradle.kts`:

- `versionCode` — целое, строго больше предыдущего (1 → 2 → 3 …);
- `versionName` — человекочитаемая («1.0», «1.1»).

## 3. Иконка и название

- Название (RuStore Console): «Денежный поток — финансовый отчёт».
- Иконка приложения: замените дефолтную в `app/src/main/res/mipmap-*`
  (или добавьте adaptive-icon в `mipmap-anydpi-v26`). Рекомендуется
  изумрудно-золотая в стиле приложения, 512×512 для витрины.

## 4. Сборка артефакта

AAB (предпочтительно для RuStore):

```bash
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew bundleRelease
# → app/build/outputs/bundle/release/app-release.aab
```

Либо APK:

```bash
./gradlew assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

## 5. Реклама (если включаете в этом релизе)

См. `docs/RUSTORE_ADS.md`. Помните: реклама добавляет разрешение INTERNET и
обязательную политику конфиденциальности (`docs/PRIVACY.md`).

## 6. Карточка в RuStore Console

- Категория: Игры / настольные (или Образование/Финансы — на выбор).
- Возрастной рейтинг: укажите наличие рекламы.
- Описание, скриншоты (снимите с разных экранов: отчёт, профессии,
  скоростная дорожка, 202).
- Ссылка на политику конфиденциальности (обязательна при наличии рекламы/сети).
- Загрузите `app-release.aab`, заполните «Что нового», отправьте на модерацию.

## 7. Юридическое

«Денежный поток»/CASHFLOW — товарные знаки. Приложение — независимый помощник
для ведения финансового отчёта, не аффилировано с правообладателем. При
коммерческой публикации убедитесь, что название/описание/иконка не нарушают
права на товарные знаки (избегайте оформления «как официальное приложение»).
